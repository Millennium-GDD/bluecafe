# Publication scope and history

This checkout was prepared from the original project in a separate clone. The two original commits were rewritten to remove `Assets/BlueCafe/Content`, `evidence`, acquisition `tools`, and the old local documentation. The original workspace/history remains local and was not rewritten. Updated authored runtime source and portable documentation were then integrated.

Only `main` and reviewed release tags are pushed. Do not push the original project with `--mirror` or `--all`: local checkpoint refs and original commits contain excluded material. Do not re-add content, caches, captures, app-data/discovery files or build outputs. The entire external content and evidence directories are ignored.

The Linux alpha artifact is distributed through Releases rather than committed to source history. It contains app code, Unity runtime libraries, UI resources/font and authored layout-only examples. It does not contain the downloaded game asset pack.

No project-wide source license has been chosen. Public visibility is not an open-source license or rights clearance for external game content.
